# Thesis_Project_KU
Repo containing scripts and files for conducting Z Kubala thesis project

## Files contained

### Bash Scripts folder
- dem_wroclaw computes elevation to used for driving grades in Wroclaw
- wroclaw_streets_bash.sh: file that retrieves street network for Wroclaw Poland
- syracuse_streets_bash.sh: retrieves street network for Syracuse New York

### Scalgo Data
- Scalgo exports of Wroclaw rain based on depth or rainfall.
- It's more important that we have the profile of where rainwater collects, because the script will then set a threshold based on parameters of depth.

### Output files cached
- This is helpful when the files were previously generated by scripts to go right to the training step.  I.e. rasters, street networks

## Main scripts
- thesis_project.py references two scripts below to put it all together
- cleaning_streets.py goes through and extracts important fields and aspects of the bash output needed for training.  Excludes walking paths or places cars can't drive
- Scalgo-bbox.py is important because it takes the bounding box of scalgo raster to have an exact overlay for streets and elevation
